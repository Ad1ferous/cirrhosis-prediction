# Model Card: Прогнозирование исходов цирроза печени

## 1. Описание модели
- Название: Модель мультиклассового прогнозирования исходов цирроза печени.
- Тип задачи: Мультиклассовая классификация.
- Версия: 1.0.
- Архитектура: Ансамблевые алгоритмы (Random Forest, CatBoost, XGBoost).

## 2. Назначение и решаемая задача
Модель создана для помощи врачам в оценке рисков у пациентов с циррозом печени. Она анализирует медицинские показатели и предсказывает один из трех возможных исходов:
- C (Censored): пациент жив, состояние стабильно.
- CL (Censored due to liver transplantation): пациенту потребовалась трансплантация печени.
- D (Dead): высокий риск летального исхода.
Модель выступает как вспомогательный инструмент для принятия клинических решений.

## 3. Входные данные
На вход подаются структурированные данные пациента:
- Демография: возраст, пол, количество дней наблюдения.
- Лабораторные анализы: билирубин, холестерин, альбумин, медь, щелочная фосфатаза, АСТ, триглицериды, тромбоциты, протромбиновое время.
- Клинические признаки: стадия болезни, наличие отеков, асцита, увеличение печени, сосудистые звездочки.
- Лечение: тип применяемого препарата.

## 4. Выходные данные
Модель возвращает вероятность для каждого из трех классов. Итоговый прогноз — это класс с максимальной вероятностью.

## 5. Метрики качества
Для оценки модели использовались следующие метрики:
- Accuracy: общая доля правильных предсказаний.
- F1-score: гармоническое среднее между точностью и полнотой. Важна для несбалансированных классов, чтобы модель не игнорировала редкие исходы.
- ROC-AUC: способность модели разделять классы между собой.

## 6. Ограничения и особенности применения
- Модель обучена на исторических данных конкретного исследования и может хуже работать на пациентах из других регионов.
- Не учитывает динамическое изменение анализов во времени, работает только со срезом на момент поступления.
- Прогноз носит рекомендательный характер и не заменяет очного осмотра и решения врача.
