Model Card: Прогнозирование исходов цирроза печени
1. Описание модели (Model Details)
Название: Мультиклассовая модель прогнозирования исходов цирроза печени.
Тип задачи: Мультиклассовая классификация (3 класса).
Версия: 1.0.
Архитектура: Ансамблевые методы.
2. Назначение и решаемая задача (Intended Use)
Модель предназначена для помощи врачам в оценке вероятных исходов заболевания у пациентов с циррозом печени на основе их клинических данных.
Задача: предсказать один из трех исходов:
C (Censored): пациент жив на момент окончания исследования.
CL (Censored due to liver transplantation): пациенту была проведена трансплантация печени.
D (Dead): летальный исход.
Модель является инструментом поддержки принятия решений, а не средством для полностью автоматической постановки диагноза. Окончательное решение всегда принимает врач.
3. Входные данные (Inputs)
На вход модели подаются структурированные данные пациента:
Демографические: возраст, пол.
Лабораторные анализы: уровень билирубина, холестерина, альбумина, меди, щелочной фосфатазы, АСТ (SGOT), триглицеридов, тромбоцитов, протромбиновое время.
Клинические признаки: стадия заболевания, наличие отеков, асцита, увеличение печени, сосудистые звездочки.
Лечение: тип принимаемого препарата.
4. Выходные данные (Outputs)
Модель выдает вероятность принадлежности пациента к каждому из трех классов (C, CL, D). Итоговый прогноз — это класс с наибольшей вероятностью.
5. Метрики качества (Metrics)
Для оценки использовались следующие метрики:
Accuracy (Доля правильных ответов): показывает общую точность модели.
F1-score (средний по классам): важен, так как классы могут быть несбалансированы (например, смертей меньше, чем выживших). Эта метрика учитывает и ложные срабатывания, и пропуски.
ROC-AUC (One-vs-Rest): показывает, насколько хорошо модель разделяет классы между собой.
6. Ограничения и особенности применения (Limitations)
Модель обучена на исторических данных конкретного исследования. Она может хуже работать на пациентах из других регионов или с сопутствующими заболеваниями, не представленными в данных.
Модель не учитывает динамическое изменение показателей во времени, только данные на момент наблюдения.
Прогноз модели не заменяет профессиональную медицинскую экспертизу.
